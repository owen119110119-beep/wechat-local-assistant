# 安装前后检查

安装助理必须在开始时核对宿主实际工具，使用统一入口补齐依赖，完成后按功能说明可用范围。导入Skill或复制文件不代表功能已就绪。不要求用户安装其他Skill。

## 自动安装与继续

先发现已有部署与知识库。新部署用Skill目录中的`scripts/install.py --host codex或workbuddy --target 专用目录 --vault 知识库目录`。重复相同命令只检查和补依赖，不覆盖已有代码、账号或笔记。旧版本先用`upgrade.py`检查并安全升级，再运行安装检查；不能直接覆盖自定义文件。不要替用户重新扫码。

需要本机音频转写时追加`--with-media`，才下载转写依赖和模型。微信已有语音文字无需本机转写。默认补齐公众号、网页、小红书读取、Office、PDF、OCR、浏览器和视频处理依赖。当前依赖需要Python >=3.12，优先使用3.12；统一入口自动发现合适的已有/捆绑Python，缺少时使用官方winget安装，保留旧Python。Codex同时补齐二维码、SILK并验证Node、PowerShell；缺少Node/PowerShell时尝试官方安装，受权限/网络限制就明确引导，不关闭审批。安装前需已有官方Codex/WorkBuddy；若连运行安装脚本的Python都没有，助理先检测`py -3.12`等运行时，没有则通过`winget install --id Python.Python.3.12 --exact --source winget`安装官方Python，重新发现真实解释器后继续，不猜路径。旧部署的旧Python环境不自动覆盖，说明兼容性问题并协助保留原配置迁移；不能用装成功几个包来报告成功。

Obsidian先查已有安装，缺少时用官方安装途径补齐，保留笔记与插件；检测不完整或仅找到安装记录时，先核对原位置，不盲目重装。检测和安装有等待上限，安装器超时时先读回实际结果，勿重复启动；给出官方下载入口，不阻塞其他依赖检查。不要更改微信、系统代理、VPN或证书，也不要复用其他Skill的依赖目录。下载失败保留已安装部分，报告失败阶段和解决办法，用同一命令继续。取消即停止，不继续扫码或启动。

部署目录可单独运行`python scripts/setup-assistant.py`修复。`--check`只读导入和版本检查，不安装、不下载、不写报告；它不能代替首次安装的实际功能验证。`--with-media`仍只在需要本机转写时使用。兼容入口`setup-content.py`转交同一检查。结果保存在本机`.runtime/installation-check.json`，不得提交或打包。退出码2表示仍有依赖或宿主检查未完成，不能报告全部成功。

## 宿主工具：必须实际核对

Python脚本不能证明宿主模型/工具可用。安装助理须检查实际微信助理会话可用工具并做最小无隐私验证；不能拿桌面会话的工具清单代替手机助理的能力。

|能力|核对与缺少时的引导|
|---|---|
|本机执行、读写|在部署目录执行简短命令，知识库临时文件写入读回后删除；不能改已有笔记。缺少则启用宿主本机工具并给予限定目录权限。|
|图片理解|核对支持图片的模型及真实附件输入；缺少则引导切换支持图片的模型。OCR不等于模型看过图。|
|图像编辑|确认实际图像编辑工具可调用及登录/额度；没有则明确修图暂不可用，继续提供已验证的识别/PDF功能，不能自动改用付费服务。|
|联网搜索|做一次无隐私公开检索并核对来源；没有则引导开启联网工具，正文抓取不等于检索工具。|
|附件收发|手机发一张无隐私图片，助理读取并回传无隐私PDF/图片，用户确认实际收到。只入队不能算已送达。|

将实际核对结果写在部署本机JSON，字段为`shell`、`file_read`、`file_write`、`image_read`、`image_edit`、`web_search`、`attachment_receive`、`attachment_send`。每项含`status`（`available`、`unavailable`或`not_checked`）及简短`evidence`；例如`{"file_write":{"status":"available","evidence":"专用临时文件写入并读回一致，已删除"}}`。用`--host-checks 本机JSON路径`汇总；未验证不得填available，未知项保留not_checked。安装前先核对本机工具，附件往返须在绑定后完成；最终再运行同一检查合并结果，不重复绑定。

检查显示缺项时，在绑定前先简短告知哪些功能可用、哪些缺什么、如何补齐；用户可选择先用已通过部分。最终按功能交付，不用一个“安装成功”掩盖缺项。无需向普通聊天主动播报检查字段或内部状态。

## 群聊和平台登录

指定群后端仅适用于Windows Codex、受支持的官方微信4本机文字数据库。安装时说明此条件，不自动读群或取钥。用户要求整理群时运行`setup-chat-history.py --check`，按实际候选自然选择并记住账号，再按需启用；失败解释实际原因，保留原设置。不能承诺直接读取手机历史。

小红书遇实际登录要求时打开项目专用浏览器，由用户登录，不能要求发Cookie。软件依赖通过不表示所有链接都可读；公众号验证页、视频播放源未公开或平台不支持时如实说明，不把封面当视频正文。
