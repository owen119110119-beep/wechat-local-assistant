# 指定群整理（Windows Codex）

用于电脑微信已同步的文字记录。先部署并连接Codex助理，电脑微信保持登录；本机数据库读取仅在用户要求启用后配置。它不会接管微信、改代理/证书、向群发消息，或直接读取手机数据库。

在部署目录执行：

```powershell
python scripts/setup-chat-history.py --check
python scripts/setup-chat-history.py --enable
```

脚本按运行中官方微信进程定位程序，不限定安装盘符；按微信配置、Windows文档位置和OneDrive文档位置发现数据。中文、空格和自定义数据位置可用；不全盘搜索。先用`--check`只读发现，唯一目标直接启用，多个账号/目录/进程自然询问用户按位置或用途选择，不猜选、不要求手机输入命令或内部编号。提供位置后内部用`--data-dir`继续发现；确认的候选内部用`--account`、`--pid`传入。找不到时引导用户在微信设置的文件管理/存储位置查看并提供路径，区分数据目录与程序安装目录。

启用成功后将账号和程序位置保存在部署本机配置，后续复用，进程PID变化不重问。旧安装已有缓存可复用并补记位置；原位置失效或用户要求换账号时才再次澄清，不自动读取另一个账号。失败保留原配置和缓存；取消不改选择。无需移动微信文件或更改网络。配置和候选路径只留本机，不放进笔记或安装包。

脚本使用项目内独立依赖，将本机解密材料保护在当前用户专用缓存。PowerShell 7不在PATH时可传`--pwsh`实际程序路径。受平台权限限制时正常申请所需权限，不关闭审批或绕过拒绝。

启用完成后服务会在后续请求读取配置，无需重启。可接着完成本轮群整理，保留原来给出的群名、重点与时间，不让用户重新下指令。名称核对、时间/重点追问、整理与类型建议按[交互规则](interaction.md)完成。没有预设群名，不要求先选分类或输入编号。

可处理空格/括号、名称片段及有限错字；近似或重名需用户区分。找不到不能直接认定未同步，读取失败也不表示群里没有消息。记录缺失、数据库更新或当前读取方式不适用时说明具体情况，不修改微信版本或反复取钥；确需重新认证时由用户明确后使用`--enable --refresh`。

停用执行`python scripts/setup-chat-history.py --disable`，后续请求生效。停用保留记住的位置，不删除原聊天或笔记。缓存与配置只留本机，不能提交或打包分享。
