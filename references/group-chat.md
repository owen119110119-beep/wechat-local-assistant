# 指定群整理（Windows Codex）

用于电脑微信已同步的文字记录。先部署并连接Codex助理，电脑微信保持登录；本机数据库读取仅在用户要求启用后配置。它不会接管微信、改代理/证书、向群发消息，或直接读取手机数据库。

在部署目录执行：

```powershell
python scripts/setup-chat-history.py --check
python scripts/setup-chat-history.py --enable
```

脚本使用项目内独立依赖，核对官方微信进程，将本机解密材料保护在当前用户专用缓存。多个进程或账号不明确时，由助理核对安装位置及用户使用的账号，再用`--pid`、`--account`指定；这些参数不要求用户在手机输入。PowerShell 7不在PATH时可传`--pwsh`实际程序路径。受平台权限限制时正常申请所需权限，不关闭审批或绕过拒绝。

启用完成后，等助理空闲再用`scripts/stop.ps1`、`scripts/start.ps1`重新加载服务。随后从微信自然要求整理一个群，名称核对、时间/重点追问、整理与类型建议按[交互规则](interaction.md)完成。没有预设群名，不要求先选分类或输入编号。

可处理空格/括号、名称片段及有限错字；近似或重名需用户区分。找不到不能直接认定未同步，读取失败也不表示群里没有消息。记录缺失、数据库更新或当前读取方式不适用时说明具体情况，不修改微信版本或反复取钥；确需重新认证时由用户明确后使用`--enable --refresh`。

停用执行`python scripts/setup-chat-history.py --disable`，空闲后重新加载。停用不删除原聊天或笔记。缓存与配置只留本机，不能提交或打包分享。
