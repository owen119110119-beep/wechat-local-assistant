# 微信-codex/workbuddy聊天智能助理

通过微信与电脑上的 Codex 或 WorkBuddy 自然对话，并把公众号文章、重点知识与待办整理到 Obsidian。

核心功能：自由讨论和执行任务；发送公众号链接后整理要点，通过文字或语音补充需求，完成分析与查询，再按你的分类意见保存到知识库。

**1.2.0新增图片助理。** 连续上传课件、白板或截图，补充重点后整合为PDF返回微信；也支持图片问答、文字提取、翻译和按要求修图。

整理完成后会单独给出分类建议，询问是否保存到知识库及是否设置待办；文字或语音明确意见后直接执行，不重复确认。

**1.1.0整合公众号与指定群整理。** Windows Codex用户可按需启用群消息读取：自然说出群名，补充关注点与时间范围，整理后再选择保存类型。

也可整理小红书图文、网页，以及图片、PDF、DOCX、PPTX、XLSX和音视频文件；配图文字、扫描页和视频画面在本机读取。

## 下载安装

[下载 Skill 安装包](https://github.com/owen119110119-beep/wechat-local-assistant/releases/latest/download/wechat-local-assistant.zip) · [版本页](https://github.com/owen119110119-beep/wechat-local-assistant/releases/latest)

- **Codex**：将安装包解压到用户的 `.codex/skills/wechat-local-assistant`，在对话中调用 `$wechat-local-assistant`，让助理安装微信接口并配置知识库。Codex 部署适用于 Windows。
- **WorkBuddy**：在“技能 → 添加技能 → 上传技能”导入安装包，在微信助理会话中启用此 Skill，使用 WorkBuddy 原生微信连接。
- **Obsidian**：告诉助理你的知识库路径；已有安装和笔记会保留，未安装时由助理协助安装。

首次安装需登录宿主并用手机扫码连接微信，已经运行的助理不用重复绑定。

已有安装：导入新版Skill后，让助理升级原部署目录，保留配置、微信绑定与笔记，无需重新扫码。手动步骤见[Codex安装与升级](references/codex-install.md)或[WorkBuddy安装](references/workbuddy.md)。[旧版1.0.0](https://github.com/owen119110119-beep/wechat-local-assistant/releases/tag/v1.0.0)保留用于回退（旧版只有整理公众号文章与自然对话功能）。

## 文章与日常交流

1. 发送公众号链接：读取正文，反馈简洁要点，询问希望重点备注或补充什么。
2. 补充需求：完成分析、查询或其他任务，再反馈要点；单独给出分类建议，询问如何分类及是否记入待办。

视频号、其他视频、小红书、网页及文件链接也遵守以上流程：先整理并追问，收到补充后再整理、建议分类；不会因为链接类型或过去的收藏习惯而自动保存。暂时读不到内容时会说明并继续沟通。

你可以随时继续讨论或提出其他任务，不需要固定格式。文字和已转写语音同等处理；明确分类或待办意见后直接保存，无需再次确认。纯聊天不自动入库。

|类型|分类方式|
|---|---|
|普通信息|我的随手转发 → 普通信息库 → 信息类别 → 日期|
|重点关注|我的随手转发 → 重点关注 → 用途|
|主题待办|待办事项|
|群消息摘要|微信群消息 → 信息类型 → 日期|

公众号与素材使用“待办事项”和“我的随手转发”，群摘要需要保存时再建立“微信群消息”。一篇文章只入普通或重点之一，相关待办可单独建立。类别随内容和用途建议；重点关注的日期只用于判断时效。

## 指定群消息（Windows Codex）

先按[群聊整理](references/group-chat.md)启用本机读取，随后在微信说“帮我整理某群的信息”即可。名称不明确时会核对，未给重点或时间时会自然追问，并结合消息量建议近三天至一周的范围；无需配置确认、编号或固定口令。

微信程序和数据位置自动识别；多账号或多个目录时自然询问选择并记住，后续不用重复提供。找不到时会引导你从微信设置中提供存储位置，不需要移动文件或重装微信。

整理完成后单独建议保存类型，明确选择就保存。只读取你指定的群，不向群发消息，不改变微信或代理。内容来自电脑微信已同步记录，不能直接取得手机独有记录；图片、语音和视频未实际分析时会说明。

## 运行条件

电脑须开机联网，Codex 或 WorkBuddy 须运行。打开 Codex 并加载聊天时，会自动启动微信助理；无需 Windows 登录自启或周期检查。

**注意：同一微信的 ClawBot 入口重新绑定其他助理，会替换原来的助理连接。**
